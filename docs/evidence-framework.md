# Evidence framework

Statuses: VERIFIED, PARTIALLY VERIFIED, UNDER VALIDATION, ROADMAP.

Published technical evidence uses PMRA-BENCH-NNN identifiers. Each states its measurement, scope and limitation. Simulation, shadow observation and runtime records are treated as distinct evidence classes. Component benchmarks are reported as component benchmarks.

Detailed technical evidence is available for qualified review through the PMRA Systems Technical Review & Evidence Package.
